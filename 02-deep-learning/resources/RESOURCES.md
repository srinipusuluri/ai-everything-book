# 🔗 Resources — Deep Learning

## Courses
| Course | Why | Link |
|---|---|---|
| **Karpathy — Neural Networks: Zero to Hero** | Builds autograd, then an LLM, from nothing. The best deep learning teaching on the internet. | https://karpathy.ai/zero-to-hero.html |
| **fast.ai — Practical Deep Learning for Coders** | Top-down; you train a good model in lesson 1 | https://course.fast.ai/ |
| **DeepLearning.AI Deep Learning Specialization** | Andrew Ng's structured treatment | https://www.coursera.org/specializations/deep-learning |
| **Stanford CS231n — CNNs for Visual Recognition** | The best notes on backprop and convnets | https://cs231n.github.io/ |
| **NYU Deep Learning (LeCun & Canziani)** | Free lectures, strong theory | https://atcold.github.io/NYU-DLSP21/ |
| **MIT 6.S191 Intro to Deep Learning** | One-week intensive, updated yearly | http://introtodeeplearning.com/ |
| **PyTorch official tutorials** | The reference you will actually return to | https://pytorch.org/tutorials/ |

## Repositories worth cloning
| Repo | What's inside |
|---|---|
| https://github.com/karpathy/micrograd | A 100-line autograd engine. Read it in one sitting. |
| https://github.com/karpathy/nn-zero-to-hero | Notebooks for the course above |
| https://github.com/pytorch/examples | Canonical training scripts (MNIST, ImageNet, DCGAN, …) |
| https://github.com/d2l-ai/d2l-en | Dive into Deep Learning, full source |
| https://github.com/rasbt/deeplearning-models | ~60 clean reference implementations |
| https://github.com/lucidrains/vit-pytorch | Readable implementations of vision transformer variants |
| https://github.com/huggingface/pytorch-image-models (timm) | 1000+ pretrained vision models; the transfer-learning workhorse |
| https://github.com/Lightning-AI/pytorch-lightning | Training-loop framework; read it to see what a mature loop needs |
| https://github.com/labmlai/annotated_deep_learning_paper_implementations | 60+ papers implemented with side-by-side notes |

Clone the starter set with: `bash ../_tools/clone_repos.sh 02-deep-learning`
